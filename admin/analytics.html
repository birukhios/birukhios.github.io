About the page paths. The portfolio is a single page with client-side routing — the URL never changes as you move between Work, Play and the case studies. Left alone, GA would record one / view per visitor no matter how much they browsed. So the site sends a pageview per screen using virtual paths: /work, /play, /about, /resume, /contact, and /case/<id> for each case study. That's what you'll see under Pages and screens.

Cookies. GA4 sets cookies and, for visitors in the EU/UK, generally requires a consent banner under GDPR/ePrivacy. If you'd like, a cookieless alternative (or a consent banner) can be added.
